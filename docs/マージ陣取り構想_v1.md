# マージ×陣取り 構想 v1 — 2026-08-10

**状態: 方向転換の検討中。** 社長が試作を触って判定するまで、ファミコンウォーズ型（`game/`）は現状のまま凍結も廃止もしない。

## 1. なぜ方向転換を検討するのか

きっかけは2つの会話が重なったこと。

1. **「虫が軍隊を組む」は生物学的に嘘**であり、賢い子はそこを見抜く。操り手（ネクロマンサー）等の物語で補強する案を検討していた
2. 社長が Merge Dragons（マージして呪われた土地を癒やし取り戻すゲーム。全世界1,000万DL超）の魅力を挙げ、**戦争よりマージ×陣取りに魅力を感じる**と表明

マージ×陣取りに変えると、**1の嘘そのものが消える**。敵を「虫の軍隊」にする必要がなくなり、荒地・外来種が敵になる。ゲームの目的が「殺し合い」から「すみかを取りもどす」に変わる。

商業監査（2026-08-10）との整合も良い:
- Advance Wars 系は既に何本もあり、読み替えだけでは埋没する（Wargroove・Athena Crisis の実績が示す）
- マージ×陣地再生は Merge Dragons / Triple Town で実証済みの型で、スマホ・タップ操作・低年齢と相性が良い

## 2. 生物学への翻訳 — ドラゴンより虫のほうが「正しくなる」

Merge Dragons のマージはファンタジーの約束事だが、社会性昆虫では実在の生態になる。

| マージ段階 | 実在の裏づけ |
|---|---|
| はたらきアリ ×3 → ぎょうれつ | 道しるべフェロモン |
| ぎょうれつ ×3 → アリづか | 超個体（スーパーオルガニズム）・カースト分化 |
| ミツバチ ×多 → 蜂球（将来） | 日本ミツバチがスズメバチを集団で蒸し殺す実在の防衛 |

裏返しも学びになる: **カブトムシ・カマキリは単独性なのでマージできない**。
「マージできる虫とできない虫がいる」というルール自体が「社会性昆虫とは何か」を教える。
単独性の虫には別の役割を与える（試作ではカブトムシだけが荒地をたがやせる）。
**個の力の虫と群れの力の虫の協力**が、このゲームの協調の形になる。

### 用語の決めごと

**「進化」とは呼ばない。** 進化は世代を超えた変化であり、これは群れの成長・分業。
ポケモン式に「しんか」と呼ぶと、本作の生物学的正確さの看板に傷がつく。
試作では「ぎょうれつになった」「アリづかになった」と、なった先の名前で語る。

## 3. 敵の設計 — 実在の侵略者

敵は **アルゼンチンアリの巨大コロニー**（実在の侵略的外来種。在来アリを駆逐しながら陣地を広げる）。

- 「たたかい」はしない。**数の力でかこんで「おいかえす」**（倒れた虫は にげていく、の原則をそのまま維持できる。死の描写問題も発生しない）
- 巣も破壊ではなく「ひっこしていく」
- 荒地（blight）が毎ターンじわじわ広がる圧が、ターン制の緊張を作る

外来種問題は日本で現実の社会テーマ（ヒアリ・アルゼンチンアリ）。学びの柱「摂理」に「生態系のバランスを崩すもの」として自然に接続する。

## 8. 実機テスト1回目（2026-08-11）— 遊べる以前の不具合3件と修正

社長の実機（iPhone）テスト結果: **「画面が進まず、相手のアリがどんどん浸食してくるだけ。スクロールできない。ポップアップが消せない」**。

原因は3つとも実装の欠陥で、しかも私（Claude）の検証手法の穴が通してしまった。

| 症状 | 原因 | 修正 |
|---|---|---|
| 画面が進まない | タイルの大きさを**画面の幅だけ**から決めていて、盤14行が縦に収まらず、操作の起点の女王アリづかが**画面外**にあった | 幅と高さの**両方**から計算して盤を必ず画面内に収める |
| スクロールできない | `touch-action:none` を body 全体にかけていた（画面外の女王づかに永遠に届かない） | body は通常操作に戻し、ドラッグの誤スクロール防止は**虫の要素だけ**に限定 |
| ポップアップが消せない | チュートリアルが**画面下固定のポップアップ**で、自陣に覆いかぶさりタップを吸っていた。閉じるボタンもない | 盤の**上**の帯に移動（何も覆わない）。「とばす」ボタンを追加 |
| （追加の手当て） | 詰んだときの逃げ道がない | 「はじめから」ボタンを常時表示。敵の進軍は**プレイヤーが1回マージするまで**待つ（上限約50秒） |

### 検証手法の教訓（そのまま作業ルールにする）

**JSの関数を直接呼ぶ検証は、画面の不具合を素通しする。**
前回の検証はロジックをJS経由で呼んでいたため全項目緑だったが、実機では1タップも成立しなかった。
今回から**実際の指と同じ座標タップ・座標ドラッグだけ**で最初の1マージまで通す検証に変えた。
確認済み: 盤が画面内に収まる / 隠れスクロールがない / チュートリアルが女王づかを覆わない /
座標タップでたまごが出る / 座標ドラッグだけで3マージ成立 / とばす・はじめからが効く / JSエラーなし。

## 9. 実機テスト2回目（2026-08-11）— 「分かりやすさが足りない」への試作3

草を減らす方法が不明。アリ塚を増やして増産する仕組みがない」。

| 指摘 | 対応 |

| 強くなる過程が見えない | **格が上がると大きさが変わり（0.56→0.78→0.95倍）、色が変わり（CSSフィルタで赤褐色→黒赤）、つよさの数字（1/4/16/30）をバッジで常時表示** |
| 陣地が広がる理屈が不明 | マージ地点の周り3×3が開く演出（白フラッシュ＋✨）を強化し、チュートリアルと獲得時バナーで明言 |
| 草を減らす方法が不明 | **かりとりを新設**: アリを🌿にドラッグすると1.6秒もぐもぐして開墾。ごほうびに🥚(40%)や🟤つちのやま(30%)が見つかる |

| もっとMerge Dragonsふうに | さわらなくても生産が回る（放置で🥚が湧く）。**あと1つでマージできる2つ組は光って誘う** |

経済ループが Merge Dragons 型の2チェーンになった:
- 生きものチェーン: 🥚 → 🐜1 → 🐜4 → 🐜16（＋発見枠の🪲30）
- 設備チェーン: 🌿かりとり → 🟤 → ⛰️（生産設備。増やすと加速）

検証（座標タップ・座標ドラッグのみ、9項目）: 数字バッジ表示 / 大きさの段差 / 色の変化 /
自動増産 / 3マージ / かりとり開墾 / ごほうびドロップ / 🟤×3→⛰️ / JSエラーなし。

## 10. 実機テスト3回目（2026-08-11）— 「自衛権しかない」への試作4

社長評: **「アリは自分で森を切り開けない。光っているカブトムシも開けない。しかし敵はどんどん森を開拓してくる。このアンフェアを是正しない限り、自衛権しかない」**。

数字で裏づけが取れた。60秒放置（プレイヤー操作なし）で:

```
敵の陣地   27 → 33（+6）
味方の陣地 27 → 27（+0）
```

### 原因は3つ重なっていた

1. **敵は歩くだけで草を開けた**。1tickにつき3体が無条件に開拓（≒1.15マス/秒）
2. **味方はドラッグ必須**。1マスあたり ドラッグ1回＋1.6秒。自動では1マスも進まない
3. **いちばん効いていた見落とし**: かりとりを実装した後も、**アリは隣を刈り終えるとその場で止まり、二度と前へ進まなかった**。
   「1マスは刈れるが前線が動かない」ので、体感は「切り開けない」になる。
   光る✨マスは自陣から5マス先にあり、手作業では実質到達不能だった

### 試作4での是正

| 変更 | 中身 |
|---|---|
| **虫が自分で開拓する** | 隣に草があれば**ドラッグなしで自動的にかりとる**。格が上がるほど速く広い |
| **前線が自分で進む** | 刈り終えた虫は、いちばん近い草へ自陣の中を1マス進む。**これが本体の修正** |
| **カブトムシは開拓の王者** | 周囲3×3を一気に開墾（1.5秒）。眠りから覚めさせる値打ちが生まれた |
| **敵の開拓を抑える** | 新しく開ける草は**1tickに1マスまで**（3マスから） |
| 無言の失敗をなくす | 届かない場所・敵陣に置いたとき、理由を出す |

かりとりの能力（実装値）:

| 虫 | 時間 | 範囲 |
|---|---|---|
| はたらきアリ(1) | 3.0秒 | 隣1マス |
| へいたいアリ(4) | 2.0秒 | 隣1マス |
| おおあごへいたい(16) | 2.0秒 | 隣すべて |
| カブトムシ(30) | 1.5秒 | 周囲3×3 |

**是正後の実測（虫2匹を置いて60秒）: 味方 +22 / 敵 +8。** 攻守が逆転した。

### 途中で見つけた不具合

アリが**すでに目標の草の隣に立っている**と、足場を自分自身で塞いでいるため
「そこはまだ遠いよ」と拒否される。狙い撃ちのドラッグが効かない原因だった。修正済み。

### 設計として残る問い

虫が自律的に前進するため、**プレイヤーの役割は「どこに置くか」で向きを決めること**に変わった。
Merge Dragons の放置感には近づいたが、操作感が薄くなりすぎていないかは実機の判断待ち。
