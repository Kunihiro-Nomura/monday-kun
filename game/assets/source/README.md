# 生成した元画像の置き場（任意）

グラフィック担当が生成した**加工前の高解像度画像**を、ここに置けます。
ゲームには使われません。比較・作り直し・記録のために残す場所です。

## 使い方

候補が複数あるときは、末尾に記号をつけて並べてください。

```
game/assets/source/kabuto-a.png
game/assets/source/kabuto-b.png
game/assets/source/kabuto-c.png
```

ここに置いてもらえれば、**設計担当（Claude）の側で以下を実行できます**。

1. 背景除去（色かぶりの除去を含む）
2. 96×96 へのリサイズと占有率の調整
3. 受け入れ検査（`scripts/check-assets.mjs`）
4. **実際のゲーム画面に並べて 48px での判別性を確認**
5. 採用したものを `game/assets/units/<id>.png` として確定

つまり、**後処理はグラフィック担当がやらなくても構いません**。
生成した元画像をここに置くだけで、あとは自動で進みます。

## 注意

- 元画像は大きいので、**採用が決まったら不要な候補は削除**してください
- 透過PNGを直接出力できる場合は、そのほうが確実です（色かぶりが起きないため）
