# 昆虫戦争（プロトタイプ）

カブトムシやトンボなど、本物の昆虫の力をつかってたたかうターン制の作戦ゲーム。
遊びながら昆虫のことを学べる、子供向けの学習要素を組みこんでいます。

全体の企画は リポジトリ直下の [`PLAN.md`](../PLAN.md) を参照。
このフォルダは **フェーズ P0〜P2 のプロトタイプ**（移動・戦闘・占領・生産・ターン交代）です。

## iPhone で遊ぶ

1. このフォルダを HTTPS で公開する（GitHub Pages なら `https://<ユーザー名>.github.io/monday-kun/game/`）
2. iPhone の Safari でそのURLを開く
3. 共有ボタン → **「ホーム画面に追加」**

ホーム画面から起動すると全画面になり、電波がなくても遊べます（Service Worker でキャッシュ）。
進行状況と昆虫ずかんは端末の localStorage に自動保存されます。

## 手元で動かす

ES モジュールを使っているので、ファイルを直接開くのではなく HTTP で配信してください。

```sh
npx http-server game -p 8123 -c-1
# → http://localhost:8123
```

## テスト

```sh
# ルールの単体テスト（ブラウザ不要）
node game/test/engine.test.mjs

# 画面のながれ（iPhone サイズの実ブラウザ）
npx http-server game -p 8123 -c-1 &
node game/test/ui.test.mjs           # スクリーンショットの保存先を引数で指定できる
```

`engine.test.mjs` はマップデータの検証も兼ねています。行の長さ違い・知らない地形文字・
ユニットの重なり・通れない地形への配置などは、ここで落ちます。80面を書き足していくときの
安全網として使ってください。

## ファイル構成

```
game/
  index.html            画面の骨組み（タイトル / ステージ選択 / ゲーム / ずかん）
  css/style.css         見た目。セーフエリアと指で押しやすいサイズを意識
  js/
    main.js             画面のながれと入力のせいぎょ（つなぎ役）
    engine.js           ルールの本体。描画も入力も知らない純ロジック
    ai.js               敵AI（Lv1）
    render.js           Canvas への描画
    data/
      units.js          昆虫ユニット + 生態情報 + 攻撃力表
      terrain.js        地形
      maps.js           ステージ（世界1の3面）
  test/                 テスト
  sw.js                 オフライン対応
```

**エンジンとデータを分けている**のが設計の要です。80ステージぶんのマップは `data/maps.js` に
足していくだけで増やせ、バランス調整は `data/units.js` の数値だけで完結します。

## 今のプロトタイプでできること

- 世界1の3ステージ（クリアすると次が開く）
- 8種類の昆虫ユニット（アリ・カマキリ・テントウムシ・カブトムシ・クワガタ・
  ミイデラゴミムシ・スズメバチ・オニヤンマ）
- 移動 / 直接・間接攻撃 / 反撃 / 占領 / 生産 / 収入 / 回復 / 勝敗判定
- 敵AI（Lv1: 近くの敵を攻撃し、樹液場を占領しにくる）
- 昆虫ずかん（戦場に出た虫が自動で登録され、実物の生態が読める）
- クリア時の「まめちしき」

## 素材について

ユニットの絵文字はプロトタイプ用の仮置きです。特に **クワガタ（🦂）と
オニヤンマ（🦋）は該当する絵文字がない**ための代用なので、P7 でオリジナルの
ドット絵に差しかえます。
