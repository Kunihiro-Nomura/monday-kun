# 『昆虫戦争』 グラフィック発注仕様書

画像生成AI（または絵師）に**そのまま渡せる指示書**です。
**全52カット**（盤面26カット＋図鑑26点）を作っても**バラバラにならない**ことを最優先に設計しています。

> **なぜ仕様書が必要か**
> 画像生成そのものは安く速い。難しいのは**量産ではなく統一**です。
> 1枚ずつ生成すると、線の太さ・彩度・光の向き・見る角度・虫どうしの大きさの比率が
> 全部ずれます。ゲームの盤面に並べた瞬間に「寄せ集め」に見えてしまう。
> ここを固定するのがこの文書の役割です。

**改訂履歴**

## 0. 生物分類についての重要な注意

**この作品に登場する「虫」には、昆虫ではないものが含まれます。**
学習教材として出すので、絵の指示でも図鑑の表示でも、ここは絶対に混同させません。

| 生物 | 正しい分類 | 指示のしかた |
|---|---|---|
| **ハリガネムシ** | **類線形動物門**（昆虫ではない） | 「昆虫ではない、細長い線形の生物」と明示する |
| **タイワンアリタケ** | **菌類**（子嚢菌門） | 「アリに寄生した菌類の子実体」として描く。虫として描かせない |
| **ハエトリグサ／モウセンゴケ／ウツボカズラ** | **植物** | 植物として描く |
| **ダンゴムシ** | 甲殻類（昆虫ではない） | 図鑑に出す際は分類を正しく表示 |
| **クモ・ダニ** | クモ綱（昆虫ではない） | 同上 |

→ 図鑑には**分類の欄**を設け、「昆虫のなかま」「昆虫ではないなかま」を区別して表示します。

## 1. 共通仕様（全カット共通・ここは絶対に変えない）

| 項目 | 指定 |
|---|---|
| **視点** | **真上からの俯瞰（トップダウン）**。標本写真と同じ見え方 |
| **向き** | 頭が**画面の上**。**左右の重心を揃えた自然な姿勢**（機械的な完全対称にはしない） |
| **キャンバス** | 生成は 1024×1024 の正方形。最終的に 96×96 へ縮小して使う |
| **余白** | 被写体の外側に**上下左右とも最低5%の余白**を残す（トリム処理のため） |
| **背景** | 単色。**被写体に含まれない色を選ぶ**（§1.3） |
| **影** | **焼き込まない**。影はゲーム側でコードで付ける |
| **光源** | 左上からの柔らかい光。全カットで統一 |
| **タッチ** | 図鑑イラスト風のセミリアル。**擬人化しない**（顔・表情・手足の人間化なし） |
| **輪郭** | 濃い色の輪郭線をはっきり付ける（縮小しても形が残るように） |
| **色** | 実物に忠実な自然色。彩度は少し高めでよいが、蛍光色は使わない |
| **ポーズ** | 静止。**識別器官**（角・大アゴ・鎌・捕獲脚・産卵管など）が上から見て明確に見えること |

> 「武器」という言葉は使いません。甲冑化・ファンタジー化を誘発するためです。
> 角も大アゴも、あくまで**その虫を見分けるための器官**として描かせます。

### 1.1 チームの色分けについて（重要な設計判断）

青軍・赤軍の区別は、**虫の体色では行いません**。
虫の色を変えると「本物のカブトムシの色」と矛盾し、学習教材として成立しなくなるためです。

→ **虫は実物の色のまま1体だけ作り、チームの区別は足元の台座と枠でゲーム側が付ける。**
　 これで**作る枚数が半分**になります。

### 1.2 大きさの比率（生成後に必ず揃える）

上から見た体長を基準に、**キャンバス内で占める割合**を指定します。
これを守らないと「アリとカブトムシが同じ大きさ」になります。

| 区分 | キャンバス占有率 | 該当する生物 |
|---|---|---|
| 極小 | 35% | アリ、アブラムシ、アリヅカコオロギ |
| 小 | 50% | テントウムシ、ミイデラゴミムシ、コマユバチ、ネジレバネ、テッポウムシ、ヤゴ、モウセンゴケ、タイワンアリタケ |
| 中 | 70% | カマキリ、スズメバチ、ゲンゴロウ、タガメ、ヤドリバエ、ハリガネムシ、カブトムシの幼虫、ハエトリグサ、ウツボカズラ |
| 大 | 85% | カブトムシ、オオクワガタ、オニヤンマ |
| 特大 | **90%** | ヘラクレスオオカブト |

> 特大を100%にすると§1の「最低5%の余白」と矛盾するため、**上限は90%**です。

### 1.3 背景色の選び方（重要・抜け落ち対策）

**全カットを緑背景にすると、緑色の被写体が背景ごと抜けてしまいます。**
被写体の色に応じて背景を使い分けます。

| 被写体の主色 | 背景色 | 該当 |
|---|---|---|
| 緑・黄緑が主体 | **マゼンタ `#FF00FF`** | カマキリ、アブラムシ、ハエトリグサ、ウツボカズラ、ゲンゴロウ |
| それ以外（茶・黒・灰・赤・白） | **グリーン `#00FF00`** | 上記以外すべて |

原則は「**被写体に含まれない色を背景にする**」。
生成AIが透過PNGを直接出力できる場合は、そちらを優先して構いません。

## 2. プロンプトのひな形

各生物の行にある「特徴」を `{{特徴}}` に差し込むだけで使えます。
英語のほうが多くの画像生成AIで安定します。

### 日本語版

```
真上から見下ろした{{和名}}（{{学名}}）のゲーム用アイコン。
{{特徴}}
頭を上に向け、左右の重心を揃えた自然な姿勢。
図鑑イラスト風のセミリアルな描き方で、擬人化しない。顔や表情は付けない。
濃い輪郭線をはっきり付ける。光は左上から。影は描かない。
背景は単色の{{背景色}}。正方形。周囲に少し余白を残す。実物に忠実な色。
```

### 英語版（推奨）

```
Top-down view icon of a {{English name}} ({{学名}}) for a strategy game.
{{English feature}}
Head pointing up, naturally balanced posture, centered, with a small margin around it.
Semi-realistic field-guide illustration style. Not anthropomorphic, no face, no cartoon eyes.
Strong dark outline. Soft light from upper left. No cast shadow, no ground.
Flat solid {{background}} background. Square canvas. Accurate natural coloration.
```

### 統一のコツ

1. **最初に1体だけ作って承認する**（カブトムシ）
2. それを**スタイル参照画像**として指定し、残りを生成する
3. 同じシード値・同じモデル・同じ設定で通す。途中でモデルを変えない

## 4. 生成後の後処理（自動化できる）

生成した画像は、そのままではゲームに使えません。以下は**スクリプトで一括処理**できます。

1. **背景除去** — 単色背景（緑またはマゼンタ）を透過に抜く
2. **余白トリム** — 被写体の外接矩形で切り出す
3. **大きさ調整** — §1.2 の占有率に合わせて 96×96 の中に配置
4. **トーン統一** — **彩度・明度・黒レベルのみ**を共通の値に補正する
5. **輪郭の追加** — 縮小で潰れた輪郭を1px描き足す
6. **書き出し** — `game/assets/units/<id>.png`

> **⚠️ 共通パレットへの減色はしません。**
> 全カットを同じ限定パレットに寄せると、実物の色（テントウムシの赤、カマキリの緑、
> カブトムシの赤褐色）が壊れ、学習教材としての正確さを失います。
> 統一するのは**色そのものではなく、彩度・明度・黒レベルという「調子」**だけです。
>
> **⚠️ ベクター化（SVG化）もしません。**
> セミリアルな陰影のある絵をベクター化すると、階調が段々になって破綻します。
> ベクター化は §7 の「SVGで一から描く」方式を選んだ場合にのみ行います。

このセッションでは Adobe 連携により、**背景除去・トリム・リサイズ**を実行できます。
生成そのもの（テキストから画像を作る機能）は含まれていないため、
**生成は外のAIで行い、仕様書・後処理・実機での品質確認はこちら**で持つのが現実的な分担です。

## 5. 受け入れ基準（ここを通らなければ作り直し）

**必ず、実際のゲーム画面に並べた状態で確認します。** 1枚ずつ拡大して見ると全部よく見えます。

- [ ] **48px に縮小しても**、他の生物と見分けがつく（いちばん大事）
- [ ] 草はら（黄緑）・雑木林（濃い緑）・池（青）の**どの地形の上でも埋もれない**
- [ ] 頭の向きが全カットで揃っている
- [ ] **大きさの比率**が正しい（アリ ＜ テントウムシ ＜ カブトムシ ＜ ヘラクレス）
- [ ] 線の太さ・彩度・光の向きが**他のカットと揃っている**
- [ ] 実物の色・形から大きく外れていない（**学習教材としての正確さ**）
- [ ] 擬人化されていない（顔・表情が付いていない）
- [ ] 背景が完全に抜けている（**緑の被写体が欠けていないか特に確認**）
- [ ] 昆虫でない生物（ハリガネムシ・菌類・植物）が、昆虫のように描かれていない

## 8. カブトムシ基準画像（v1 承認ずみ）

### 8.1 この画像の位置づけ

**生物学的な基準ではなく、「線・彩度・光・輪郭」のスタイル基準として使います。**
ゲーム駒としては合格ですが、図鑑レベルの厳密さでは様式化が残っているためです。

### 8.2 残りの25カットで持ち込まないこと（次バッチの注意点）

基準画像で様式化が見られた箇所です。**スタイルは真似させ、これらは真似させません。**

| 箇所 | 基準画像の状態 | 残りのカットでの指示 |
|---|---|---|
| **胸角まわり** | やや様式化されている | 胸角は頭角より小さい控えめな突起として描く |
| **触角** | 先端が小さな手のように見える | 触角は**片状（葉が重なった形）の球桿部**として描く。指状にしない |
| **脚のトゲ** | 過剰に鋭く多い | 脛節のトゲは実物どおり**数本の控えめな棘**に留める |
| **頭角の長さ** | まだやや長め | **体長の約3分の1**を上限とし、先端の分岐はコンパクトに |

### 8.3 図鑑用カブトムシは別に用意する

盤面用は「48pxで判別できること」が最優先なので、多少の様式化は許容します。
一方、**図鑑には形態的に正確なカブトムシを別カットで用意**し、
盤面用とは役割を分けます（§7 の「盤面と図鑑で作り方を分ける」方針）。
