# 『昆虫戦争』 グラフィック発注仕様書

画像生成AI（または絵師）に**そのまま渡せる指示書**です。
50点近い絵を作っても**バラバラにならない**ことを最優先に設計しています。

> **なぜ仕様書が必要か**
> 画像生成そのものは安く速い。難しいのは**量産ではなく統一**です。
> 1枚ずつ生成すると、線の太さ・彩度・光の向き・見る角度・虫どうしの大きさの比率が
> 全部ずれます。ゲームの盤面に並べた瞬間に「寄せ集め」に見えてしまう。
> ここを固定するのがこの文書の役割です。

---

## 1. 共通仕様（全カット共通・ここは絶対に変えない）

| 項目 | 指定 |
|---|---|
| **視点** | **真上からの俯瞰（トップダウン）**。標本写真と同じ見え方 |
| **向き** | 頭が**画面の上**。左右対称に配置 |
| **キャンバス** | 生成は 1024×1024 の正方形。最終的に 96×96 へ縮小して使う |
| **背景** | 完全な単色（`#00FF00` 等の抜きやすい色）。透過でもよい |
| **影** | **焼き込まない**。影はゲーム側でコードで付ける |
| **光源** | 左上からの柔らかい光。全カットで統一 |
| **タッチ** | 図鑑イラスト風のセミリアル。**擬人化しない**（顔・表情・手足の人間化なし） |
| **輪郭** | 濃い色の輪郭線をはっきり付ける（縮小しても形が残るように） |
| **色** | 実物に忠実な自然色。彩度は少し高めでよいが、蛍光色は使わない |
| **ポーズ** | 静止。武器（角・鎌・大アゴ・針）が**上から見て明確に見える**こと |

### 1.1 チームの色分けについて（重要な設計判断）

青軍・赤軍の区別は、**虫の体色では行いません**。
虫の色を変えると「本物のカブトムシの色」と矛盾し、学習教材として成立しなくなるためです。

→ **虫は実物の色のまま1体だけ作り、チームの区別は足元の台座と枠でゲーム側が付ける。**
　 これで**作る枚数が半分**になります。

### 1.2 大きさの比率（生成後に必ず揃える）

上から見た体長を基準に、**キャンバス内で占める割合**を指定します。
これを守らないと「アリとカブトムシが同じ大きさ」になります。

| 区分 | キャンバス占有率 | 該当する虫 |
|---|---|---|
| 極小 | 35% | アリ、アブラムシ、アリヅカコオロギ |
| 小 | 50% | テントウムシ、ミイデラゴミムシ、コマユバチ、ネジレバネ |
| 中 | 70% | カマキリ、スズメバチ、ゲンゴロウ、タガメ、ヤドリバエ |
| 大 | 85% | カブトムシ、オオクワガタ、オニヤンマ |
| 特大 | 100% | ヘラクレスオオカブト |

## 2. プロンプトのひな形

各虫の行にある「特徴」を `{{特徴}}` に差し込むだけで使えます。
英語のほうが多くの画像生成AIで安定します。

### 日本語版

```
真上から見下ろした{{和名}}（{{学名}}）のゲーム用アイコン。
{{特徴}}
頭を上に向け、左右対称。図鑑イラスト風のセミリアルな描き方で、擬人化しない。
濃い輪郭線をはっきり付ける。光は左上から。影は描かない。
背景は単色の緑（#00FF00）。正方形。実物に忠実な色。
```

### 英語版（推奨）

```
Top-down view icon of a {{English name}} ({{学名}}) for a strategy game.
{{English feature}}
Head pointing up, bilaterally symmetric, centered.
Semi-realistic field-guide illustration style. Not anthropomorphic, no face, no cartoon eyes.
Strong dark outline. Soft light from upper left. No cast shadow, no ground.
Flat solid green background (#00FF00). Square canvas. Accurate natural coloration.
```

### 統一のコツ

1. **最初に1体だけ作って承認する**（おすすめは**カブトムシ**）
2. それを**スタイル参照画像**として指定し、残りを生成する
   （多くの画像生成AIに「参照画像でスタイルを固定する」機能があります）
3. 同じシード値・同じモデル・同じ設定で通す。途中でモデルを変えない

## 4. 生成後の後処理（自動化できる）

生成した画像は、そのままではゲームに使えません。以下は**スクリプトで一括処理**できます。

1. **背景除去** — 単色背景を透過に抜く
2. **余白トリム** — 虫の外接矩形で切り出す
3. **大きさ調整** — §1.2 の占有率に合わせて 96×96 の中に配置
4. **減色** — 全カット共通のパレットに寄せて、色調のばらつきを消す
5. **輪郭の追加** — 縮小で潰れた輪郭を1px描き足す
6. **書き出し** — `game/assets/units/<id>.png`

> このセッションでは Adobe 連携が使えるので、**背景除去・トリム・リサイズ・ベクター化**は
> こちらで実行できます。生成そのもの（テキストから画像を作る機能）は今の連携には含まれていないため、
> **生成だけ外のAIで行い、指示書と後処理はこちらで持つ**のが現実的な分担です。

## 5. 受け入れ基準（ここを通らなければ作り直し）

**必ず、実際のゲーム画面に並べた状態で確認します。** 1枚ずつ拡大して見ると全部よく見えます。

- [ ] **48px に縮小しても**、他の虫と見分けがつく（いちばん大事）
- [ ] 草はら（黄緑）・雑木林（濃い緑）・池（青）の**どの地形の上でも埋もれない**
- [ ] 頭の向きが全カットで揃っている
- [ ] 虫どうしの**大きさの比率**が正しい（アリ ＜ テントウムシ ＜ カブトムシ ＜ ヘラクレス）
- [ ] 線の太さ・彩度・光の向きが**他のカットと揃っている**
- [ ] 実物の色から大きく外れていない（学習教材としての正確さ）
- [ ] 擬人化されていない（顔・表情が付いていない）

## 7. すすめかたの提案

1. **カブトムシ1体だけ**生成する → 見比べて方向性を決める
2. 承認したカブトムシを**スタイル参照**にして、盤面ユニット25点を一気に生成
3. 後処理を一括でかけ、**実際のゲーム画面に並べて**受け入れ基準を確認
4. 通らなかったものだけ作り直す
5. 図鑑用の26点は、ゲームが面白いと確認できてから

**盤面と図鑑で作り方を分けるのも有効です。**
盤面のユニットは統一感が命なので SVG（コードで描く）にして完全に揃え、
図鑑のイラストは美しさが命なので生成AIや写真を使う、という分担です。
