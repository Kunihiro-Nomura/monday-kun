## 1. 目的

50人規模製造業(アルファメック)の社長個人業務を対象に、AIで以下を実現する:

- **スリム化**: 定型業務(メールチェック、月次集計、文書下書き)をAIに移管
- **効率化**: 情報の検索・要約・突合を数分で完了させる
- **拡張**: 一人では処理しきれなかった情報量(全商談・全カイゼン・全査定材料)を判断に組み込む
- **インプット増**: 記憶頼みだった定性情報(口頭・電話・訪問)を構造化して蓄積
- **論理的判断**: 経営判断(人事・設備投資・査定)を、根拠データと判断記録を伴う形にする

## 3. 入力の3系統(ユーザー定義)

1. **商談情報**: 媒体あり(メール・FAX・見積書・売上データ・生産管理データ・営業記録)+媒体なし(電話・訪問・来訪の記憶)
2. **従業員査定情報**: 定量(LINE WORKS・カイゼン提出・目標管理シート・作業履歴・勤怠・有給・資格)+定性(口頭・評判・出来事・問題)
3. **経理情報**: ISO9001月次入力(残業・売上・月次報告書・買掛)

出力: 年1回ISO9001マネジメントレビュー(方針策定→目標管理シート→力量表更新)+随時の経営判断(人事・設備投資・査定)

## 9. ガバナンス(監査領域の具体化)

### 9-1. 拠り所とする公的基準

- **個人情報保護委員会の生成AI注意喚起(2023-06-02)**: 従業員・顧客の個人データをAIに入力するのは「利用目的の範囲内」かつ「AI事業者が入力データを機械学習に使わないことを確認済み(学習オフの法人契約)」の場合のみ。氏名は社員番号等に置換して入力する。
  https://www.ppc.go.jp/news/careful_information/230602_AI_utilize_alert/
- **AI事業者ガイドライン(総務省・経産省)**: AI利用者に「利用ルール整備・従業員教育・出力の人間による最終確認」を要求。社内ルールは「技術/法務/組織運用」の3領域で構成するのが定石。
  https://www.ipa.go.jp/disc/committee/expert-group-on-aigfb.html

### 9-2. アルファメックAI利用ルール(A4 2〜3枚で策定する)

既存の「個人用AI使用原則」(Notion AI作業ハブ)を組織版に昇格させ、以下4点に絞る:

1. 許可ツール一覧(法人契約・学習オフ確認済みのもののみ。無料個人アカウントの業務利用は禁止)
2. 入力禁止情報(顧客図面・個人情報・原価・パスワード。人事情報は仮名化必須)
3. AI出力は必ず人間が確認してから使用(「AIは下書き・分類・集計まで。社外送信・データ削除・人事記録の書き込みは必ず人間が実行」)
4. 相談窓口1名の指名と、朝礼+年1回の教育

### 9-3. AIエージェントの暴走対策(Human-in-the-loop設計)

- 権限の最小化: エージェントには承認済みツール・最小限のデータアクセスのみ与える
- 決定境界の明文化: 定型処理は自動可、「金額基準超・社外送信・削除・人事記録変更」は人間承認ゲート必須
- 全アクションのログ保存(監査領域の実行ログDBに集約)
- 参考: https://wandb.ai/site/articles/guardrails-for-ai-agents/

### 9-4. 査定・人事へのAI適用 5原則

1. **最終判断は必ず人間**: AIは事実収集と下書きまで。AI出力そのままの評価は人事権濫用と判断されるリスク
2. **個人データ入力条件の遵守**: 上記PPC注意喚起の通り。仮名化+学習オフ法人契約
3. **透明性**: AIをどの工程で使うか従業員に事前説明し、評価根拠を本人に説明できる状態を保つ
4. **バイアスの定期監査**: 「日報を書くのが上手い人が有利」等の偏り増幅を評価分布で定期チェック
5. **不服申立て経路**: AI関与評価への異議窓口と人間のみでの再評価プロセスを事前に用意。導入初期は賞与・昇格への反映を限定
