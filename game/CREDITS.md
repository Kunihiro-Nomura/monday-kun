# 素材のクレジットとライセンス記録

ゲームで使っている素材の出所を記録します。
**新しい素材を追加したら、必ずここに追記してください**（[`AGENTS.md`](../AGENTS.md) 参照）。

## グラフィック

| ファイル | 作り方 | モデル / 作者 | 生成日 | 商用利用 | 備考 |
|---|---|---|---|---|---|
| （まだありません） | | | | | |

記録する項目:

- **作り方**: 画像生成AI / 手描き / ストック素材 のどれか
- **モデル / 作者**: 使ったモデル名（バージョンまで）または作者名
- **生成日**: いつ作ったか
- **商用利用**: 利用規約で商用利用が許されているかを確認した結果
- **プロンプト**: 生成AIの場合は使ったプロンプトを残す（下の「プロンプト記録」へ）

## プロンプト記録
